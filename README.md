# Flask Task Manager

A simple task manager web app built with Flask.

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Search tasks
- Priority and due date

## Tech Stack
- Python (Flask)
- HTML/CSS
- CSV for storage

## How to Run
1. Install Flask
2. Run:
   python app.py
3. Open browser at http://127.0.0.1:5000
